Sobre mí

Estudio Ingeniería en Ciencias de la Computación en la ESPOL, nivel 300I. Me apasiona el desarrollo backend y la ingeniería de datos porque un dato aislado no dice nada, pero al relacionarse, estructurarse y fluir a través de una buena lógica interna, se convierte en el motor que mueve experiencias completas.

Tengo un enfoque práctico, curioso y flexible ante los retos. En competencias de programación, hackathons y datathons, me he enfrentado a escenarios donde el valor principal radica en la adaptabilidad, lo que implica analizar el problema en el momento, investigar rápido las herramientas necesarias y adaptarme al entorno para construir una solución efectiva y eficaz. Para mí, los lenguajes y frameworks son herramientas para demostrar versatilidad, mientras que mi foco principal se mantiene en la arquitectura de backend, el modelado de datos, la optimización de código y la creación de lógica interna funcional.

Además del aspecto técnico, me involucro de lleno en el lado operativo y humano de las iniciativas. He participado activamente en organizaciones estudiantiles coordinando tanto la gestión administrativa como el soporte técnico detrás de proyectos y eventos, lo que me ha enseñado a estructurar procesos, trabajar en equipo y asegurar que las ideas se ejecuten con propósito.

EcoTrack

Gestión de residuos y reciclaje urbano.

Sistema con estructuras de datos implementadas desde cero, como una cola de prioridad para despachar vehículos, una pila para el centro de reciclaje, una lista circular y un mapa hash. Calcula la utilidad ambiental por zona, guarda los datos en archivos y ofrece interfaz gráfica y de consola.

  • Java 17
  • Maven
  • JavaFX
  • MVC
  • Estructuras de datos

Go PLY Analyzer

Analizador léxico y sintáctico de código Go.

Analiza un subconjunto del lenguaje Go y reporta tokens y errores con su línea. Incluye una interfaz gráfica con editor, simulación de ejecución, generación de logs y pruebas automáticas. Sigue en desarrollo, con la meta de incorporar la fase de análisis semántico. Fue un proyecto colaborativo.

  • Python
  • PLY
  • Tkinter
  • ttkbootstrap
  • unittest

Tecnologías

Herramientas aplicadas en los proyectos del curso y en otros proyectos, junto con su uso en cada caso.

React, TypeScript y Vite

En Dashboard, para construir componentes reutilizables de cabecera, alerta e indicadores, con tipado estático y compilación rápida.

Material UI y API de Open-Meteo

En Dashboard, Material UI para la maquetación de la interfaz y la API de Open-Meteo, consumida con fetch, para obtener los datos del clima en tiempo real.

HTML, CSS y JavaScript

En Chancho Fest Landing, para personalizar la plantilla Directive con jQuery, y en Furina Landing Page, para el menú adaptable, las animaciones de aparición con IntersectionObserver y el formulario de contacto.

GSAP y ScrollTrigger

En este portafolio, para las animaciones que se activan al desplazarse por la página.

Git y GitHub

Para el control de versiones en todos mis repositorios, con ramas y pull requests en Chancho Fest Landing, y la publicación de este portafolio mediante GitHub Pages.

Java y Maven

En EcoTrack, para implementar desde cero la cola de prioridad, la pila, la lista circular y el mapa hash, con java.util como apoyo. Maven gestiona la compilación y las dependencias.

JavaFX y patrón MVC

En EcoTrack, para la interfaz gráfica con tablas, formularios y gráficos, organizada en modelo, vista y controlador.

Python y PLY

En Go PLY Analyzer, para definir los tokens del analizador léxico y la gramática del analizador sintáctico.

Tkinter y ttkbootstrap

En Go PLY Analyzer, para la interfaz gráfica con editor de código y botones para analizar, simular la ejecución y generar logs.

unittest

En Go PLY Analyzer, para las pruebas automáticas de los analizadores y de los algoritmos de prueba.
